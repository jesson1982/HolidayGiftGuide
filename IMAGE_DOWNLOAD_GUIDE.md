## Download Instructions

### From Unsplash
1. Go to https://unsplash.com
2. Search for the suggested terms
3. Click on desired image
4. Click "Download free" button
5. Choose appropriate size
6. Rename file as specified above
7. Place in assets/images/ directory

### From Pexels
1. Go to https://www.pexels.com
2. Search for the suggested terms
3. Click on desired image
4. Click "Free Download"
5. Choose appropriate size
6. Rename file as specified above
7. Place in assets/images/ directory

## Image Optimization Tips
- Compress images to ensure fast loading (target < 200KB per image)
- Use WebP format when possible for better compression
- Maintain consistent aspect ratios within image categories
- Ensure all images have alt text in HTML
- Test image loading speed before final site launch
